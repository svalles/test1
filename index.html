Tutorial

Bienvenido al portal para aprender el sistema de paginación Intel x86. En este simulador podrás:

  • Cargar un valor de CR3.
  • Cargar al menos 4 entradas del Page Directory (PDE).
  • Cargar al menos 4 entradas para cada Page Table (PTE).
  • Ver que las entradas de las Page Table apuntan a bloques movibles denominados "Página".
  • Observar que las entradas del Page Directory enlazan con sus correspondientes Page Table.

Utiliza los controles y realiza doble click sobre una entrada del Page Directory para cargar su Page Table, o usa el botón general.
