Tutorial

Bienvenido al portal para aprender el sistema de paginación Intel x86. Aquí descubrirás conceptos clave como:

  • Directorio de Páginas: La estructura que contiene las referencias a las tablas de páginas.
  • Tablas de Páginas: Donde se almacena la información de mapeo entre direcciones virtuales y físicas.
  • Traducción de Direcciones: El proceso que realiza la CPU para convertir una dirección virtual en una dirección física.

Continúa explorando para ver un ejemplo interactivo del sistema en acción.
